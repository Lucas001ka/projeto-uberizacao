PROJETO DE UBERIZAÇÃO — COMO USAR

1. Extraia este ZIP.
2. Abra index.html no navegador para testar o site.
3. Envie os arquivos index.html, uberizacao.html, wendel.html, ryan.html e style.css para a raiz do repositório do GitHub.
4. Envie também a pasta imagens, que contém as fotos reais enviadas para Wendel e Ryan.
5. As entrevistas estão separadas: wendel.html contém as respostas de Wendel; ryan.html contém as respostas de Ryan.
6. No GitHub, confirme as alterações e aguarde o GitHub Pages publicar a versão atualizada.
7. Use o endereço público para gerar o QR Code.
